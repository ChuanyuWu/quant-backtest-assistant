# 量化交易策略回测系统（网页版）使用说明

## 一、快速开始

1. **启动**：双击 `start.bat`。**首次运行会自动安装依赖**（需要联网，等几分钟），装完自动启动，浏览器会打开 `http://127.0.0.1:8666`。之后每次启动都是秒开。
   - 如果自动安装失败，在项目文件夹打开终端手动执行：`pip install -r requirements.txt`
   - 也可以在 PyCharm 里直接运行 `start.py`（用的是 PyCharm 项目的解释器）。
3. **首次使用先拉数据**：进入「数据管理」页 → 数据源选 akshare（免费无需Token）→ 股票数量选 200只 → 开始拉取，等待进度条完成（约几分钟）。之后可点「更新本地股票」或开启每日自动更新。为保持前复权一致，更新会全量刷新已有历史，耗时取决于股票数量与源站响应。
4. **关闭**：直接关掉启动时的黑色命令行窗口即可。

## 二、各模块说明

### 行情分析
- 顶部选择股票和择时策略，K线图自动加载，买卖信号以红绿三角标在K线上。
- **参数滑块**：拖动快线/慢线等参数，信号实时重画，无需点按钮。
- 「▶ 回测」弹出完整回测报告（净值曲线对比**沪深300指数**真实基准、回撤曲线、12项指标、逐笔明细）。若指数数据拉取失败会自动退回"买入持有"基准。
- 「模拟交易」用虚拟账户资金执行一次完整交易，账户余额持续累计，可随时清零重置。
- 右侧选股面板：执行选股后，**点击结果卡片直接加载该股票K线**。

### 大盘指数
- 上证、深证成指、创业板指、沪深300、中证500、科创50 六大指数一键切换。
- K线 + MA5/10/20 + 成交量，拖动/缩放查看任意区间；数据本地缓存，每天最多联网刷新一次。

### 策略工坊
- 单次回测：完整参数面板（择时/止损/买入比例），报告内嵌显示。
- SVM 参数寻优：随机采样 → SVM代理模型 → 候选验证，自动搜索 MACD+止损最优组合，后台异步执行有进度条。
- **参数敏感性热力图**：寻优完成后展示快线×慢线收益曲面。最优参数处在大片暖色平台中说明稳健；孤立热点则可能是过拟合。
- 「应用到回测面板」一键同步最优参数。

### 箱体分析
- 点击「开始批量分析」，后台异步处理全部本地股票。
- 结果：11种买入条件×4种持有期的胜率/平均收益表（红涨绿跌），以及最近信号明细（T+1买入）。

### ML预测
- 先「训练模型」：随机森林 + 5折时序交叉验证 + 概率校准，输出各折准确率（对比基线）和特征重要性。
- 再「预测最新走势」：输出上涨/下跌概率、趋势方向和置信度。
- 注意：准确率是统计意义上的参考，不构成投资建议。

### 资讯情绪
- **市场情绪温度**：0~100° 综合仪表盘，由涨停/跌停家数、最高连板、炸板率、昨涨停今均涨、涨跌家数六个维度加权合成，一眼判断市场冷热。
- 情绪明细卡片：涨停/跌停/连板/炸板率等逐项展示（akshare 实时数据）。
- 财经快讯流：财联社实时快讯（失败自动切换备用源），**点击快讯可跳转原文**，点「刷新」更新。

### AI助手
- 先在「设置」页选择 AI 服务商并填对应 API Key（推荐智谱GLM，glm-4.7-flash 永久免费）；填完可点「测试 AI 连接」验证配置是否正确。
- 可附带当前股票最近10天K线作为上下文，勾选「附带相关资讯」可结合该股新闻提问。
- 四个快捷提问按钮 + 自由输入，对话有记忆，可一键清空。

### 术语词典
- 25个常用术语，支持搜索和分类浏览，点击相关术语自动跳转。

### 数据管理
- 查看本地数据状态、在线拉取和本地股票更新；展示逐股失败原因、最近尝试和成功时间。
- 数据源二选一：**akshare**（免费免Token）或 **Tushare Pro**（需在设置页填Token，并具备日线与复权因子权限）。AkShare 的东方财富行情不可用时会尝试新浪前复权接口。
- Tushare 使用 `daily` + `adj_factor` 计算前复权价格，分别诊断权限；低积分账号能访问非复权日线并不代表具备复权因子权限。逐次请求限速，权限错误不重试，网络错误和限流有限重试。

### 设置
- Tushare Token：使用 Tushare 数据源时填写。
- **AI 服务商五选一**：硅基流动（注册送额度）、DeepSeek官方（便宜）、智谱GLM（glm-4.7-flash 免费）、阿里百炼（新用户送额度）、月之暗面Kimi（长文本）。选定后填对应平台的 API Key 即可，模型留空用默认。
- **切换服务商时模型框会自动清空**（避免拿A平台的模型名去问B平台）；「测试 AI 连接」按钮可立即验证 Key 和模型是否可用，报错信息会注明当前请求的服务商和模型名。
- **每日自动更新**：先保存主数据源，勾选后于上海时间 17:30 后更新最近已收盘交易日的本地股票（需保持程序运行）。交易日历缓存到本地，失败或数据未发布按 15、30、60 分钟重试；状态持久化，重启可补跑。三次重试用尽后保留失败状态，下一天继续尝试。
- 已保存的密钥脱敏显示，留空表示不修改。

## 三、常见问题

1. **拉取数据失败/部分失败**：先在设置页点「诊断已保存的数据源配置」，查看实际接口与错误类别。权限错误需要修正 Token 或换数据源；连接失败会有限重试并尝试免费备用行情。失败不覆盖原 CSV，未返回新日期会明确显示「暂无新数据」。
2. **提示 No module named 'xxx'**：说明当前 Python 环境没装依赖。start.bat 会自动安装；如果你电脑有多个 Python（比如 PyCharm 虚拟环境 + 系统 Python），注意 bat 用的是系统 `python` 命令对应的环境，也可以改用 PyCharm 里直接运行 `start.py`。
3. **AI回答提示填写Key**：去「设置」页填硅基流动 Key。
4. **端口被占用**：如果 8666 端口被占，编辑 `config/app_config.py` 里的 `PORT` 换个端口。
5. **页面显示异常**：Ctrl+F5 强制刷新浏览器缓存。
6. **覆盖升级后必须重启**：解压新版本覆盖旧文件后，务必关掉黑色命令行窗口、重新双击 start.bat，否则后端还在跑旧代码。你的 `stock_data/` 数据和 `data/config.json` 里的密钥配置不受影响。
7. **数据存放位置**：股票CSV在 `stock_data/` 文件夹，指数缓存在 `data/indices/`，账户/缓存/配置在 `data/` 文件夹，删除 `data/config.json` 会清空已保存的密钥。

## 数据更新修复版验证

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python -m tests.live_smoke
```

`live_smoke` 是可选的真实源测试，只读查询 1 只股票的短历史区间和交易日历，不使用 Token、不写入本地行情。

运行时新增 `data/updates.json`（最近结果与自动调度状态）、`data/trade_calendar.json`（交易日历）和 `data/locks/`（线程/进程锁及请求节流）。这些文件不应提交；CSV 格式不变。应用启动时不再直接拼接不同版本的前复权异名文件，只有新完整历史通过校验、成功原子替换后才清理异名旧文件。

新增接口：`POST /api/data/diagnose` 接收 `source`，`POST /api/data/update` 使用已保存主数据源；二者均返回 `task_id`。`/api/meta` 新增 `update_status`。抓取结果 `status` 为 `success`、`partial_success`、`failed`、`up_to_date` 或 `no_new_data`，并含逐股 `items`。任务 `done` 表示执行结束，业务结果需看 `result.ok/status`，任务另提供 `outcome`。

回测缓存和 ML 模型通过行情内容指纹验证，历史前复权价格改变时不会复用旧结果。此轮未修改回测撮合与 ML 标签逻辑。
